# Tasks

Write each test first or together with the code. Every group ends green on `uv run ruff check .`, `uv run ruff format --check .`, `uv run mypy src` and `uv run pytest` (default run: no database, no network, no `real_provider`); groups that touch the database also pass `uv run pytest -m integration` against a pgvector PostgreSQL with migrations applied. Never log, print or commit resume, job or profile text, evidence, reasons, suggestions or API keys, and never make real network or LLM calls in tests (fakes only: `FakeLLMClient`, `FakeEmbeddingClient`, hand-made vectors). Start from `main` after `add-gap-analysis-engine` is merged, on a new branch (`feat/add-screening-report-and-evals`); one OpenSpec change per PR; commit messages and the PR title follow Conventional Commits (`feat: add screening report and evals`, 72 characters at most). The new code goes into existing folders (see design, decision 1); do not add a folder under `src/app/`. If a limit is reached, stop and wait for the user's command.
